# AI-decoded

Hi, I'm **Afrin** 👋, an AI Engineer from Bangalore.

I'm on a quest to become a better engineer, and in my world that means being able to break any concept down so that *anyone* can understand it.

This repo is my attempt at doing that. It's where I take AI concepts that sound intimidating and explain them in plain language, with everyday analogies, simple diagrams, and real examples.
